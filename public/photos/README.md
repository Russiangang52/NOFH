# Локальные фотографии сайта

- `news/` — 18 реальных фотографий публикаций федерации.
- `stock/` — 6 сохранённых фотографий общих блоков.
- `nofh-originals.zip` — полный архив исходного набора (создаётся при сборке).

Все файлы отдаются с вашего домена, без запросов на старый сайт.

Полная переносимая копия оригиналов находится в корне проекта: `media-library/originals`. Скрипт `scripts/restore-photos.mjs` восстанавливает эту папку до сборки Next.js. Это позволяет переносить проект даже при экспорте без бинарных файлов.

Новые фото загружаются в `/admin/photos` и сохраняются в постоянной PostgreSQL-базе (`media`), а не в недоступную для записи папку Vercel. Их адрес — `/api/media/<id>`.
